# Sai Sobila portfolio

Static HTML, CSS, and JavaScript for Sai Sobila's personal portfolio. The hero cursor effect uses an original WebGL2 dye-field renderer with a canvas fallback.

This repository is intended for GitHub Pages under `saisobila.github.io`. Publish the `main` branch from the repository root.

To preview locally:

```powershell
python -m http.server 4173
```

Visit `http://127.0.0.1:4173/`. Project entries and links are maintained in `app.js`.
